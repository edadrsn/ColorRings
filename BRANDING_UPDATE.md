# Chroma Spiral — tam ad/kimlik güncellemesi

Görünen ad, uygulama kimliği, Java paket yolu ve Android kaynak adları Chroma Spiral adına geçirildi. Yeni Android uygulama kimliği: com.chromaspiral.game. Mevcut spin-sort kayıt anahtarları korunur ancak işletim sistemi bu kimliği ayrı uygulama sayar; önceki kurulumun ilerlemesi otomatik taşınmaz. Bu kullanıcı tarafından kabul edildi; telefonda veri silme veya kurulum yapılmadı.

Önceki sürümler ve Git geçmişi yedek olarak korunur. Mevcut GitHub adresi geçerli hizmet bağlantısı olduğu için dosya içindeki dış bağlantılar otomatik olarak değiştirilmez.
